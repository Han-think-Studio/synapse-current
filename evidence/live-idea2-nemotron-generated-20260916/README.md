# 사용 안내

## 파일 선택 및 열 매핑

사용자는 프로그램 실행 시 거래내역 CSV 파일을 지정합니다. 파일 내부에 있는 날짜, 가맹점명, 금액 열의 위치와 이름을 프로그램에 알려주어야 합니다. 시스템은 사용자가 지정한 매핑 정보를 바탕으로 데이터를 해석합니다.

## 구독 패턴 검출

프로그램은 CSV 데이터에서 같은 가맹점에서 반복되는 결제 패턴을 자동으로 탐색합니다. 일정 주기(월간, 연간 등)로 동일한 금액 또는 변동된 금액의 결제가 연속적으로 발생하는지를 확인하여 구독 후보를 추출합니다.

## 결과 해석 및 리포트 출력

검출된 구독 정보는 첫 결제일, 최근 결제일, 주기, 평균 금액, 누적 지출 등 통계와 함께 화면에 표로 표시됩니다. 또한 금액 변동 이력이나 결제 간격 초과 여부를 별도 표시하고, 결과를 CSV 파일로 내보내 사용자가 확인하거나 다른 도구에서 활용할 수 있게 합니다.
