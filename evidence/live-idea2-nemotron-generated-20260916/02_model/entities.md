# 핵심 대상

## 파일 입력 및 매핑

사용자가 로컬 컴퓨터에서 거래내역 CSV 파일을 지정하여 프로그램에 전달하는 역할을 담당합니다. CSV 파일 내부의 열(날짜, 가맹점명, 금액)이 은행·카드사마다 다를 수 있으므로, 사용자가 한 번만 매핑해 주면 프로그램이 해당 열을 인식하여 데이터를 해석할 수 있도록 설정값을 저장하고 관리합니다.

## 구독 패턴 분석

매핑된 CSV 데이터를 기반으로 동일한 가맹점에서 반복되는 결제 패턴을 탐지하는 핵심 로직입니다. 첫 결제일, 최근 결제일, 주기(월간/연간), 평균 금액, 누적 지출을 계산하고, 금액 변동 이력이 있으면 인상 시점과 폭을 식별합니다. 또한 최근 결제가 예정된 주기를 넘겨 늦어지면 '종료 추정' 상태로 분류하여 관리합니다.

## 결과 산출 및 출력

분석된 구독 정보를 바탕으로 화면 표와 CSV 리포트를 생성하여 사용자에게 제공하는 역할을 합니다. 네트워크 접속 없이 로컬에서만 처리되며, 발견된 구독 목록, 인상 여부, 종료 추정 상태 등을 명확히 표시한 결과물을 출력합니다.
