# 인터페이스

## 파일 입력 인터페이스

사용자가 로컬 파일 시스템에서 거래내역 CSV 파일을 지정하여 프로그램에 전달합니다. 프로그램은 지정된 경로의 파일을 읽어들여, 첫 행을 헤더로 간주하고 나머지 행을 데이터 레코드로 처리합니다. 사용자는 CSV 파일의 열 구조가 프로그램 예상 형식과 다를 경우, 각 열(날짜, 가맹점명, 금액)이 실제 파일 내에서 어떤 위치에 있는지 매핑하는 설정을 제공할 수 있습니다. 이 인터페이스는 네트워크 접속 없이 로컬 파일 경로만으로 동작합니다.

## 분석 결과 출력 인터페이스

프로그램은 분석된 구독 정보를 기반으로 두 가지 형태의 출력을 생성합니다. 첫째, 화면 표 형태로 주요 지표(구독명, 주기, 평균 금액, 누적 지출, 인상 여부, 종료 추정 상태)를 표시합니다. 둘째, 사용자가 별도 저장할 수 있는 CSV 리포트를 생성하여 같은 구조의 데이터를 파일에 기록합니다. 출력은 결과 데이터만 포함하며, 금융 조언이나 해지 안내와 같은 부가 정보는 포함하지 않습니다.

## 데이터 처리 계약

모든 입력 및 출력 작업은 로컬 환경에서 수행되며, 외부 네트워크 통신(인터넷 접속, API 호출 등)은 엄격히 금지됩니다. 프로그램은 사용자로부터 받은 CSV 파일 데이터와 매핑 설정만을 사용하여 내부적으로 계산하며, 결과물도 사용자 지정 경로에 저장하거나 화면에 표시하는 범위 내에서만 동작합니다. 사용자 데이터는 프로그램 실행 외부로 전송되지 않습니다.
