# 다음 작업

## CSV 파싱 및 열 매핑

사용자가 CSV 파일을 업로드하면 파일 인코딩을 감지하고, '날짜', '가맹점명', '금액' 세 열이 포함되어 있는지 검증한다. 사용자로부터 각 열의 실제 위치(인덱스 또는 헤더 이름)를 입력받아 내부 표준 형식으로 정규화한다. 날짜 형식이 다양하므로 ISO 8601 변환 로직을 적용하거나 사용자가 직접 형식을 지정하도록 안내한다.

## 구독 패턴 식별

정규화된 데이터를 기반으로 가맹점명을 기준으로 레코드를 그룹화한다. 동일한 가맹점이라도 slight name variations(예: NETFLIX.COM vs NETFLIX 1234)를 허용하는 모듈러 매칭 로직을 적용한다. 각 그룹 내에서 날짜 간격을 계산하여 일정 주기(월/년/주)로 반복되는 패턴을 탐지하고, 첫 결제일, 최근 결제일, 주기, 평균 금액, 누적 지출을 산출한다.

## 인상 및 종료 상태 분석

각 구독 후보군에서 결제 금액의 시계열 변화를 감지하여 중간에 오른 적이 있으면 인상 시점과 인상폭을 별도 필드로 추출한다. 최근 결제일이 계산된 주기를 초과하면 '종료 추정' 플래그를 설정하고 해당 항목을 결과 리포트에서 분리 표시한다. 최종적으로 화면 표와 CSV 파일 형태로 정리된 리포트를 출력한다.
