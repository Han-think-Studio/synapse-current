# 내 일에서 자동화할 것 고르기

AI로 뭘 자동화하면 좋다는 말은 많이 듣는데, 정작 내 일 중에
무엇부터 손대야 하는지를 모르겠다. 하루를 기록해서 반복되는 일을
찾아내고, 그중 자동화해도 되는 것과 하면 안 되는 것을 갈라 보고 싶다.

중요한 조건:
- 추측으로 고르지 않는다. 실제로 며칠 기록한 것만 후보가 된다.
- 각 후보에는 걸리는 시간, 빈도, 틀렸을 때의 피해를 같이 적는다.
- 틀렸을 때 사람이 못 알아채는 일은 자동화 후보에서 뺀다. 빠른 것보다 되돌릴 수 있는 것이 먼저다.
- 남이 검토해야 하는 일과 나 혼자 끝내는 일을 구분한다.
- 고른 이유와 뺀 이유를 같이 남긴다. 석 달 뒤에 다시 볼 때 필요한 건 결론이 아니라 이유다.

먼저 일주일 기록하고, 후보 다섯 개만 추려서 그중 하나만 해 본다.
