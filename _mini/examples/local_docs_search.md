# 내 PC 문서 검색기

회사 문서와 개인 메모가 PDF·마크다운·한글 문서로 수천 개 쌓여 있는데,
파일 이름으로는 못 찾고 윈도우 검색은 본문을 제대로 못 읽는다.
로컬에서만 도는 검색기를 만들어서, 질문을 자연어로 넣으면
관련 문단과 그 문단이 나온 파일·페이지를 같이 보여주고 싶다.

중요한 조건:
- 문서 원문은 이 PC 밖으로 나가지 않는다. 임베딩도 로컬 모델로 만든다.
- 답을 지어내면 안 된다. 근거 문단을 못 찾으면 "없음"이라고 말해야 한다.
- 파일이 추가·수정되면 전체를 다시 읽지 않고 바뀐 것만 다시 색인한다.
- 검색 결과에는 항상 출처가 붙는다. 출처 없는 문장은 화면에 띄우지 않는다.

처음에는 폴더 하나만 대상으로 하고, 잘 되면 대상 폴더를 늘린다.
