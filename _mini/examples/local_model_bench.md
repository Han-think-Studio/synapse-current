# 로컬 모델 비교 기록

같은 작업을 모델 여러 개로 돌려 보고 "이게 더 낫다"고 말하는데,
근거가 그때그때 기억뿐이라 일주일 지나면 아무도 재현하지 못한다.
비교 자체를 기록으로 남기는 틀을 만들고 싶다.

중요한 조건:
- 같은 프롬프트, 같은 파라미터로 돌린 것만 비교한다. 다르면 비교표에 올리지 않는다.
- 모델 이름·양자화·컨텍스트 길이·샘플링 설정을 결과와 함께 저장한다.
- 판정 기준을 미리 적어 두고, 결과를 본 뒤에 기준을 바꾸지 않는다.
- 사람이 내린 판정과 자동 검사 결과를 구분해서 기록한다.
- 실패한 실행도 지우지 않는다. 실패가 결과다.

대상은 내 PC에서 도는 로컬 모델이고, 클라우드 모델은 나중에 같은 틀로 붙인다.
