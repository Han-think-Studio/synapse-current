# 유튜브 자막 요약 파이프라인

구독 채널이 많아서 하루에 올라오는 영상을 다 못 본다.
채널 목록을 주면 새 영상의 자막을 받아서 요약하고,
하루치를 모아 마크다운 한 장으로 정리해 주는 자동화를 만들고 싶다.

중요한 조건:
- 자막이 없는 영상은 건너뛰고, 건너뛴 이유를 기록에 남긴다.
- 요약에는 반드시 영상 링크와 타임스탬프가 붙는다.
- 같은 영상을 두 번 처리하지 않는다. 어디까지 처리했는지 남아 있어야 한다.
- 중간에 실패해도 그날 분량을 처음부터 다시 돌리지 않는다.
- 요약 모델은 로컬을 기본으로 쓰되, 필요하면 다른 제공자로 바꿀 수 있어야 한다.

매일 아침 한 번 자동으로 돌고, 손으로도 특정 날짜를 다시 돌릴 수 있으면 좋겠다.
