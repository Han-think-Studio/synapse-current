# 프롬프트 바꾼 게 나아진 건지 재기

프롬프트를 고칠 때마다 "이게 더 나은 것 같다"고 말하는데,
같은 입력으로 다시 돌려본 적이 없어서 나아진 건지 그날 운이 좋았던 건지 모른다.
프롬프트 변경을 측정 가능한 것으로 만들고 싶다.

중요한 조건:
- 프롬프트마다 버전이 붙고, 어떤 버전으로 돌린 결과인지 결과에 남는다.
- 비교는 같은 입력 묶음으로만 한다. 입력이 다르면 비교표에 올리지 않는다.
- 판정 기준을 먼저 적고, 결과를 본 뒤에 기준을 고치지 않는다. 고쳤다면 고친 시점이 남는다.
- 사람이 고른 것과 자동 채점이 고른 것을 구분해서 기록한다.
- 온도나 시드 때문에 흔들리는 폭을 먼저 재고, 그 폭보다 작은 차이는 개선이라고 부르지 않는다.
- 진 프롬프트도 지우지 않는다. 왜 뺐는지가 다음 사람에게 필요한 정보다.

먼저 입력 묶음 하나와 기준 하나로 시작해서, 흔들림 폭부터 잰다.
